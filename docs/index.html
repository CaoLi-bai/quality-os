Linux/macOS 将 Python 路径换成 .venv/bin/python。真实模型调用会消耗 token，仅连接隔离测试环境。

这次实测发现了什么

  • 确认异常商品型号导致 ParadeDB 查询解析失败，最终没有客服答复。
  • 区分 4 条候选产品问题与 7 条测试数据／Oracle 误报，不把机械失败全甩给研发。
  • 发现 HTTP 500 后一次提交重试 5 次且无页面错误提示；未夸大为已发生重复工单。
  • 发现 README 与实现对路由预期不一致，保留人工决策，不拿旧文档强行判新实现。
