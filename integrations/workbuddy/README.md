# WorkBuddy 集成边界

WorkBuddy 在本项目中承担协作文档与定时交付，不替代 pytest、CI 或人工发布门禁。

推荐流程：

1. 用 `需求整理输入.md` 将会议材料整理为带来源和未决项的候选输入。
2. 在 QualityOS 中执行规格校验、测试、故障证明和报告生成。
3. 用 `报告交付提示词.md` 读取 `artifacts/runs/<run-id>/report.md`，生成管理层摘要。
4. 定时任务只读取已生成证据；不得把“文档生成成功”解释成“质量门禁通过”。

不要向办公工具上传公司密钥、真实客户数据或未脱敏 Trace。本项目只使用合成订单。
